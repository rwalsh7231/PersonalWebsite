REINFORCEMENT LEARNING

ML Dynamic Map Navigation

Implemented and compared Q-Learning, DQN, and Double DQN agents in Python against dynamically changing maze environments.

  • Developed a greedy-epsilon expiration and reward system rewarding agents based on distance, terrain costs, and completion times.
  • Analyzed and visualized hundreds of episodes with Matplotlib, tracking scores and loss over time.
  • Found Double DQN converging in ~20 episodes, DQN in ~90, and Q-Learning in ~300.
